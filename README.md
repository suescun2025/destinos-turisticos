## 📝 Descripción General

**Destinos Turísticos** es una aplicación web interactiva desarrollada para revolucionar la divulgación cultural y turística global. A diferencia de las guías de viaje convencionales basadas en texto estático, este proyecto propone una **experiencia interactiva con estética HUD holográfico 3D**, fondos inmersivos reactivos y paneles dinámicos con datos históricos, arquitectónicos y estadísticos de las principales maravillas del planeta.

El portal permite navegar y profundizar en **5 grandes regiones mundiales**: **Francia, Italia, España, Estados Unidos y Egipto**, ofreciendo un recorrido interactivo por más de 20 monumentos y atracciones universales.

## ✨ Características Principales

* 🌐 **Esfera Virtual Holográfica 3D**: Visor central interactivo con perspectiva dinámica, profundidad y destellos de luz.
* 🌌 **Fondos Inmersivos Reactivos (Hover & Click)**: El entorno cambia dinámicamente al pasar el cursor o interactuar sobre cada monumento en la vista principal (París nocturno, Gran Vía madrileña, Times Square, Gran Esfinge).
* 💥 **Efectos Cinemáticos en Canvas**: Generación en tiempo real a 60 FPS de rayos láser expansivos, estelas lumínicas y partículas atmosféricas.
* 🏺 **Mecánica Interactiva del Sarcófago**: Apertura y cierre animado de la tapa del sarcófago de Tutankamón con activación de la vista de Egipto.
* 📑 **Navegación por Pestañas Fluidas**: Paneles regionales con estadísticas en tiempo real (altura, año de inauguración, datos clave) y reseñas históricas.
* 🎨 **Diseño Glassmorphism Premium**: Tarjetas translúcidas (*backdrop-filter*), tipografías modernas (*Orbitron*, *Outfit*, *Plus Jakarta Sans*) y paletas de color tematizadas.

| Monumento | Año / Altura | Descripción Destacada |
| :--- | :--- | :--- |
| **Torre Eiffel** | 1889 · 330 m | Icono mundial de hierro forjado creado para la Exposición Universal de 1889. Cuenta con 20.000 luces doradas y más de 7 millones de visitantes anuales. |
| **Museo del Louvre** | 1793 · 73.000 m² | Antiguo palacio real que alberga la famosa pirámide de cristal de I.M. Pei y obras maestras universales como *La Gioconda* y la *Venus de Milo*. |

| **Arco del Triunfo** | 1836 · 50 m | Monumento triunfal encargado por Napoleón Bonaparte que corona la majestuosa avenida de los Campos Elíseos y la Tumba del Soldado Desconocido. |
| **Basílica del Sacré-Cœur** | 1914 · 130 m colina | Templo de mármol travertino blanco ubicado en la cima de la colina de Montmartre, con una de las vistas panorámicas más impresionantes de París. |

### 5. 🇪🇬 Egipto — Giza y Civilización Faraónica

| Atracción / Elemento | Periodo Histórico | Descripción Destacada |
| :--- | :--- | :--- |
| **Gran Pirámide de Giza** | c. 2570 a.C. | La más antigua y la única de las **Siete Maravillas del Mundo Antiguo** que aún sigue en pie, construida con más de 2,3 millones de bloques de piedra. |
| **Gran Esfinge de Giza** | Dinastía IV | Colosal estatua monolítica de piedra caliza con cuerpo de león y rostro de faraón, guardiana del complejo funerario de las pirámides. |

| **Valle de los Reyes & Templos** | Imperio Nuevo | Gran necrópolis real en la orilla occidental del Nilo (Luxor/Tebas) con tumbas subterráneas talladas en la roca y policromías preservadas. |
| **El Río Nilo y Astronomía** | +4.500 años | El cauce fluvial sagrado que alimentó la civilización y guio la arquitectura de los templos alineados con los astros y solsticios. |

## 🚀 Tecnologías Utilizadas

* **HTML5 Semántico**: Estructura modular, accesibilidad (etiquetas ARIA) y optimización SEO.
* **CSS3 Vanilla**: Variables CSS nativas, efectos `backdrop-filter: blur()`, animaciones `@keyframes`, transformaciones `preserve-3d` y diseño responsivo.
* **JavaScript Moderno (ES6+)**: Control de estados de la esfera virtual, eventos de inmersión y lógica interactiva.
* **HTML5 Canvas API**: Motor liviano a 60 FPS para renderizado de partículas, rayos láser y estelas lumínicas.
* **Google Fonts**: `Orbitron`, `Outfit` y `Plus Jakarta Sans`.

## 💻 Cómo Ejecutar el Proyecto Localmente

1. **Opción A (Recomendada con Visual Studio Code)**:
   - Abre la carpeta `Destinos turísticos` en Visual Studio Code.
   - Haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"**.
   - Se abrirá automáticamente en tu navegador predeterminado en `http://127.0.0.1:5500/index.html`.

2. **Opción B (Directamente en el navegador)**:
   - Haz doble clic en el archivo `index.html` o arrástralo a tu navegador (Chrome, Edge, Firefox, Safari).

## 📤 Guía Paso a Paso para Subir a GitHub

*(Cuando decidas subir el proyecto en el futuro, solo debes ejecutar estos comandos en la terminal)*

```bash
# 1. Inicializar el repositorio Git local
git init

# 2. Agregar todos los archivos al seguimiento
git add .

# 3. Crear el primer commit
git commit -m "feat: versión inicial del portal interactivo Destinos Turísticos con HUD 3D y 5 regiones"

# 4. Establecer la rama principal como 'main'
git branch -M main

# 5. Conectar tu repositorio local con GitHub
git remote add origin https://github.com/TU_USUARIO/destinos-turisticos-web.git

# 6. Subir el proyecto a GitHub
git push -u origin main
```

## 🌐 Publicación Gratuita con GitHub Pages

1. En tu repositorio de GitHub, ve a **Settings** > **Pages**.
2. En **Build and deployment** > **Source**, selecciona **Deploy from a branch**.
3. En **Branch**, selecciona `main` y la carpeta `/ (root)`.
4. Haz clic en **Save**. En unos minutos tu web estará publicada en internet.
